# Tenglama Olami — 2-sinf uchun interaktiv matematika platformasi

"Tenglama Olami" (uz-Latn) / "Тенглама Олами" (uz-Cyrl) / "Мир уравнений" (ru) — 2-sinf (7–8 yosh) o‘quvchilari uchun maxsus ishlab chiqilgan, tenglamalar mavzusiga bag‘ishlangan to‘liq, mukammal va pedagogik asoslangan interaktiv ta'lim platformasi.

## 🚀 Asosiy Imkoniyatlar

1. **Pedagogik Yondashuv (CPA: Concrete → Pictorial → Abstract)**
   - Noma'lum tushunchasi sirli quti 📦 orqali boshlanadi va bosqichma-bosqich `x` harfiga o‘tiladi.
   - Real tarozi (balance-scale) muvozanati yordamida tenglama tushuntiriladi.
   - Teskari amal tamoyili (`x + a = b` → `x = b - a`) va tekshirish odati shakllantiriladi.
   - Sonlar doirasi: 0–20 (asosiy darslar) va 0–100 (super aralash).

2. **3 Tilda To‘liq Qo‘llab-quvvatlash (i18n)**
   - `O‘zbekcha (Lotin)`
   - `Ўзбекча (Кирилл)`
   - `Русский`
   - Barcha darslar, tushuntirishlar, so‘zli masalalar va o‘yinlar 100% to‘liq tarjima qilingan.

3. **12 Ta To‘liq Ishlaydigan Rivojlantiruvchi O‘yin**
   - 🚀 **Raketa Uchishi**: Tenglamalarni yechib yoqilg‘i to‘plash va orbitaga uchish.
   - ⚖️ **Muvozanat Ustasi**: Tarozining ikki pallasini tenglashtirish.
   - 🎈 **Sharlarni Yorish**: To‘g‘ri javobli suzuvchi sharlarni ushlash.
   - 🧩 **Tenglama Jumbog‘i**: Aralashgan kartochkalardan to‘g‘ri tenglama tuzish.
   - 🏴‍☠️ **Xazina Ovi**: Qulflangan sandiqlarni tenglamalar kaliti bilan ochish.
   - 🧠 **Xotira Juftliklari**: Tenglama va uning yechimini birlashtirish.
   - 🤖 **Robotga Yordam**: Tengoning hisob-kitob xatosini topib to‘g‘rilash.
   - 🏎️ **Tenglama Poygasi**: Robot bilan avtomashinalar poygasi.
   - 📦 **Sirli Quti Ovchisi**: 3x2 qutilar ichidagi noma'lumni ochish.
   - ⭐ **Yulduz Zinapoyasi**: Yulduzga qarab pog‘onama-pog‘ona ko‘tarilish.
   - 🎯 **Mo‘ljal**: Nishondagi to‘g‘ri javoblarni aniq urish.
   - 👫 **Ikki Kishilik Bellashuv (Pass & Play)**: Bitta qurilmada ikki bola navbat bilan musobaqalashishi.

4. **13 Ta To‘liq Bosqichli Dars (6 ta sayyora)**
   - 1-sayyora: Muvozanat (Tenglik va tarozi)
   - 2-sayyora: Sirli quti (Noma'lum va x harfi)
   - 3-sayyora: Qo‘shish tenglamalari (`x + a = b`, `a + x = b`)
   - 4-sayyora: Ayirish tenglamalari (`x - a = b`, `a - x = b`)
   - 5-sayyora: Tekshirish va so‘zli masalalar
   - 6-sayyora: Super Tengo (Aralash va ketma-ket amallar)

5. **Kattalar va O‘qituvchilar Burchagi (PIN bilan himoyalangan)**
   - Shaxsiy o‘quvchi profillari tahlili.
   - Zaif mavzular diagnostikasi va uyda yordam berish bo‘yicha pedagogik tavsiyalar.
   - Uyga vazifa yaratish va kod orqali ulashish (backend talab qilinmaydi).
   - CSV hisobot yuklab olish va JSON zaxira eksport/import.
   - Bosib chiqariladigan ishchi varaqalar (Print Worksheet).

6. **Interaktiv Sinf Proyektor Rejimi (`/classroom`)**
   - Katta shriftli, kontrastli tenglama namoyishi.
   - A guruhi vs B guruhi ball hisoblagichi.

7. **Bolalar Xavfsizligi va Maxfiylik**
   - Reklama yo‘q, tashqi tracking yo‘q, barcha ma'lumotlar faqat foydalanuvchi qurilmasida saqlanadi.

## 🛠️ O‘rnatish va Ishga Tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dasturni ishga tushirish (port 3000)
npm run dev

# Loyihani tekshirish (TypeScript typecheck)
npm run lint

# Production build qilish
npm run build
```
